## Forking and contributing

Forking [github.com/vasmarfas/sipgram](https://github.com/vasmarfas/sipgram) to prepare and submit a pull request is the normal way to contribute and this notice doesn't restrict it. Keep a fork for as long as you're working toward a PR, sync it with upstream, iterate on it. A private fork you never publish is ordinary personal use and is fine regardless.

What isn't permitted is treating a fork as an independent product rather than a contribution in progress:

* **Rebranding** a fork, giving it a different name or identity so it reads as a separate project, is not allowed; see [Name and identity](#name-and-identity) below.
* **Distributing** a fork to other users as an alternative or competing version, whether through a package registry, a container image or a release page, is not allowed even if you keep the original name.
* A fork sitting on GitHub with no active PR is not a problem by itself. Publishing or promoting it as a standalone alternative is.
